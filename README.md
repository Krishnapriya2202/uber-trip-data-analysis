# Uber Trip Data Analysis

## Objective

To analyze ride demand, revenue trends, and customer behavior using Uber trip data.

## Tools Used

* Microsoft Excel

## Data Preparation

* Cleaned date and time columns
* Created new columns:

  * Hour
  * Day
  * Trip Duration

## Analysis Performed

* Trips by Hour (Demand Analysis)
* Revenue by City
* Ride Status Analysis
* Payment Method Distribution

## Key Insights

* Ride demand is evenly distributed across hours
* Most rides are successfully completed
* Revenue is consistent across cities
* Payment methods are equally used

## Conclusion

This project demonstrates how data analysis can help understand business patterns and support decision-making in ride-hailing services.
